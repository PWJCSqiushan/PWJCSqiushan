## 你好，我是丘山

吉林大学软件工程专业大二在读，目标方向是 **AI 应用与机器学习工程**。我习惯用 AI 协作开发，把真实需求做成能上线、能验证、能持续迭代的产品；正在进行 Vibe Coding、程序设计竞赛、数学建模、计算机视觉、嵌入式等领域的学习和研究。

目前我在吉林大学人工智能学院 Solar 课题组参与 **SENSRING 声音识别指环** 的硬件与开发、尝试脉冲大模型的本地部署。代码之外，我热爱摄影创作和中长跑，并在持续学习使用 DaVinci Resolve、Lightroom、Premiere Pro、Photoshop 等工具进行影像后期处理。
