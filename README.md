吉林大学软件工程学生，也是一名摄影师和长跑爱好者。

我喜欢从真实工作流里发现问题，再把它做成能被使用、能继续迭代的完整产品。对我而言，写代码、拍照片和跑长距离并不是三件互不相关的事：它们都需要观察、取舍、耐心，以及把一件事做到终点的能力。

## 代表作品 · Featured Work

### 01 / [FurColor Studio](https://github.com/PWJCSqiushan/FurColor-Studio) <code>ACTIVE</code>

**面向兽装活动摄影的本地优先 AI 批量后期工作站。** 它来自我自己的商业摄影流程：将选片、真人脸隐私复核、样片驱动基础调色、逐图眼睛增强、水印、质检与交付串成一条可操作的流水线。

- <code>Python</code> <code>FastAPI</code> <code>OpenCV</code> <code>YuNet</code> <code>Computer Vision</code>
- 在本地处理真实照片，优先保护参与者隐私；保留摄影师人工复核权
- 用“分析 → 复核 → 训练 → 重新分析”的闭环持续校准误检

[查看工作流与快速开始 →](https://github.com/PWJCSqiushan/FurColor-Studio#readme)
